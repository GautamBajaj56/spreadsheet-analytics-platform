# 📊 Spreadsheet Analytics Platform

A full-stack spreadsheet analytics platform that enables users to upload Excel files, visualize data through interactive dashboards, and securely manage datasets using JWT-based authentication.

🔗 Live Demo: <https://excel-analytics-platform-eta.vercel.app>

## 📂 GitHub Repository

🔗 GitHub: <https://github.com/GautamBajaj56/spreadsheet-analytics-platform>

## ✨ Features

- Secure user authentication using JWT
- Upload and process Excel spreadsheets
- Parse and store spreadsheet data
- Interactive analytics dashboard
- Dynamic charts and visualizations using Chart.js
- Role-based access control
- Responsive user interface
- Cloud deployment with MongoDB Atlas

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/<username>/<repository>.git
```

### Install dependencies

Frontend

```bash
cd frontend
npm install
```

Backend

```bash
cd backend
npm install
```

### Configure Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGODB_URI=

JWT_SECRET=

CLOUDINARY_CLOUD_NAME=

CLOUDINARY_API_KEY=

CLOUDINARY_API_SECRET=
```

### Run the application

Backend

```bash
npm run dev
```

Frontend

```bash
npm start
```
